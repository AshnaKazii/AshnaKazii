**Tools:** Power BI · DAX · Power Query

### 🤖 [FinWise AI — Personal Finance Assistant](https://github.com/AshnaKazii/FinWise-AI)

An AI-powered personal finance application that provides contextual financial assistance for budgeting, expense analysis, and savings planning.

- Integrated GPT OSS 20B through the OpenRouter API.
- Implemented RAG for context-aware responses.
- Built an interactive application using Streamlit and Python.

**Tools:** Python · Streamlit · OpenRouter API · RAG · Pandas

**Tools:** Python · Tkinter · MariaDB · Pandas · Matplotlib
